# FizAk

**Нативный Android-диктофон для лекций и заметок.** Бесплатный, без регистрации. Исходный код открыт.

## Что умеет версия 1.1.0

- Длительная фоновая запись с кнопкой «Остановить» в уведомлении.
- Офлайн-распознавание русской речи на устройстве через Vosk. Модель загружается один раз по кнопке в приложении (около 45 МБ); во время работы может занимать примерно 300 МБ ОЗУ.
- Живая расшифровка во время записи; аудио и текст после остановки хранятся локально.
- Шумоподавление Android, если его поддерживает микрофон и система телефона.
- Поиск по записям и тексту, избранное, переименование, исправление расшифровки, проигрывание с выбором скорости.
- Быстрая локальная сводка из ключевых предложений. При желании можно подключить генеративную сводку Google Gemini личным API-ключом.
- Gemini-ключ шифруется на устройстве Android; транскрипт отправляется Google только после ручного выбора Gemini для конкретной сводки. Аудио Gemini не отправляется.
- Поделиться аудио или текстом, экспортировать TXT, удалять записи.
- Проверка репозитория при запуске: при ответе GitHub 404 появляется Error и кнопка системного удаления приложения.

## Важные особенности

- Для первой загрузки Vosk-модели нужен интернет; далее модель и распознавание работают офлайн.
- Запись сохраняется в WAV, 16 кГц, моно: ориентировочно **115 МБ в час**. Проверь свободное место, особенно перед длинной лекцией.
- Генеративная сводка Gemini требует собственного API-ключа Google AI Studio и интернет-доступа. Доступные квоты/условия задаёт Google, FizAk их не гарантирует. Без ключа остаётся быстрая локальная сводка.
- Распознавание, шумоподавление и качество микрофона зависят от телефона; модель Vosk — компактная, поэтому важные записи стоит проверить и исправить вручную.
- Разделение голосов разных людей и выбор конкретного говорящего пока не реализованы.
- Удаление репозитория можно определить только при доступе к интернету. Офлайн-приложение не может знать, что репозиторий удалён. Удаление приложения всегда подтверждает Android.
- APK собран CI, но приложение не проходило проверку на физическом устройстве.

## Сборка из исходников

Открой папку в Android Studio (JDK 17, Android SDK 35) или запусти `gradle assembleDebug` с Gradle 8.9+. APK: `app/build/outputs/apk/debug/app-debug.apk`.
