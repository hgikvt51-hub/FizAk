# FizAk

**Нативный Android-диктофон для лекций и заметок.** Бесплатный, без регистрации и без собственного облака.

## Уже в проекте

- Запись AAC/M4A в фоновом foreground-сервисе с постоянным уведомлением.
- Системное шумоподавление Android, если оно доступно на конкретном телефоне.
- Живая расшифровка речи средствами Android, список сохранённых записей и проигрывание.
- Локальное сокращение распознанного текста, копирование сводки, экспорт текста в TXT.
- Поделиться аудиофайлом, удалить запись; файлы находятся в закрытой памяти приложения.
- При наличии сети приложение проверяет, доступен ли репозиторий; ответ GitHub 404 показывает экран Error с кнопкой перехода к удалению приложения.
- Минимальный набор сторонних библиотек; интерфейс написан на Android SDK, не WebView.

## Важные ограничения MVP

- Запись аудио и проигрывание работают без интернета. Качество шумоподавления определяется микрофоном, системой и поддержкой NoiseSuppressor производителем.
- Распознавание выполняет системная служба Android. Автономная расшифровка доступна только если на телефоне установлена подходящая офлайн-модель русского языка; иначе системная служба может потребовать интернет. Доступность и точность не гарантируются приложением.
- Одновременная запись и распознавание поддерживаются не одинаково всеми производителями Android: проверь работу на своём устройстве перед важной лекцией.
- Сводка сейчас строится локально по ключевым предложениям, это не генеративный ИИ и её нужно перепроверять. Разделение нескольких говорящих и выбор одного целевого голоса пока не реализованы.
- Проверка удаления репозитория требует интернета. Без сети приложение не блокирует запись, поэтому не может узнать, удалён ли репозиторий.
- Android показывает собственное системное подтверждение удаления: приложение не может удалить себя незаметно.

## Сборка

Открой папку в Android Studio (JDK 17, Android SDK 35) или запусти `gradle assembleDebug` с Gradle 8.9+. APK: `app/build/outputs/apk/debug/app-debug.apk`.
