Честно о возможностях

Запись работает без сети. Для офлайн-расшифровки нужна поддерживаемая модель речи Android на русском; при её отсутствии системное распознавание может потребовать интернет. Сводка в текущей версии — локальное сокращение по ключевым предложениям, а не генеративный ИИ. Выбор конкретного голоса и разделение говорящих пока не реализованы. Не забудь проверить качество на своём телефоне перед важной лекцией.

Открытый проект

FizAk — нативное Android-приложение с открытым исходным кодом. APK собирается GitHub Actions; исходники можно скачать ZIP-архивом или посмотреть на GitHub.
